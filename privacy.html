Privacy policy

Raven Wing, a personal desktop email client. Last updated October 30, 2026.

What Raven Wing is

Raven Wing is a Windows desktop app that shows the user's Gmail. It runs only on the user's own computer. There is no Raven Wing server, website backend, account system or analytics.

Google data it uses

  • Read Gmail (gmail.readonly): to show messages, notify about new mail, and search.
  • Send email (gmail.send): only when the user clicks Send, or answers a meeting invitation.

Raven Wing cannot modify, label or delete anything in Gmail, and does not access contacts, calendar, Drive or any other Google service.

Where the data goes

  • Mail is stored only on the user's computer, in a database encrypted with AES-256.
  • Google sign-in tokens are kept in Windows Credential Manager on that computer.
  • No data is sent to the developer or to any third party. Nothing is sold, shared, or used for advertising, and no data is used to train AI or machine-learning models.
  • Images inside emails are only loaded from the internet if the user allows it.

Limited Use

Raven Wing's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing your data

In Raven Wing, Settings > Accounts > Remove account revokes Google access and deletes that account's stored mail and sign-in from the computer. Access can also be revoked at any time at myaccount.google.com/permissions.

Contact
